# Microsoft 365 Enterprise Deployment Lab

## Présentation

Ce projet simule le déploiement et l'administration complète d'un environnement Microsoft 365 pour une PME fictive de 100 employés.

## Technologies utilisées

- Microsoft Entra ID
- Microsoft Intune
- Microsoft Defender
- Windows Autopilot
- Conditional Access
- OneDrive
- SharePoint
- Teams
- PowerShell
- Microsoft Graph

## Architecture

Tenant Setup
↓
Identity
↓
Security
↓
Device Management
↓
Onboarding
↓
Operations
↓
Offboarding
